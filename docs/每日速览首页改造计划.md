# 每日速览首屏改造 — 实施计划（P0·第一项）

> 本计划**自包含**,可直接交给一个新会话执行,无需依赖历史上下文。
> 目标:把「今日速览」做成首页首屏 hero(而非新建独立页面),复用已有 `cluster_stories` + `so_what` 数据,零新采集、零新模型、零新表。

---

## 0. 目标与范围

**做(本计划范围)**
1. 新增前端组件 `DailyBriefing.jsx`,在首页主内容列**最顶部**渲染「今日速览」hero。
2. 内容 = 今日主线(事件聚类)+ 每条主线代表文章的 `so_what` 观点层。
3. 移动端自动获得主线展示(当前移动端因侧栏 `hidden lg:block` 完全没有主线)。
4. 优雅降级:接口不可达 / 无聚类结果 / 加载中,均不占版面、不报错。

**不做(明确划界,避免范围蔓延)**
- ❌ 不新建 `/daily` 路由(速览即首页首屏)。
- ❌ 不动采集层、不动 `cluster_stories`(规则版已确定可复现)。
- ❌ 不做个性化排序(那是 P1「零登录推荐排序」)。
- ❌ 不接分享后端(「分享」按钮仅做复制 `/digest/{date}` 链接,P1 才做社交卡片)。
- ❌ 不删侧栏 `MainThreadPanel`(见 §3.3 决策)。

**验收标准(Definition of Done)**
- [ ] 首页首屏(文章列表之上)出现「今日速览」区,展示当天 Top 3~4 条主线。

- [ ] 主线文章可点击跳转(当前同 `MainThreadPanel`:新标签页打开源链接)。
- [ ] 接口 404/异常/空数据时,该区静默消失,首页其余功能正常。
- [ ] 移动端(窄屏)能正常看到速览区。
- [ ] `npm run build` 通过,部署后首页加载无 console 报错。

## 1. 现状盘点(代码事实,执行前已核实)

### 1.1 数据源接口
- **路由**:`api/routes/stories.py` → `GET /api/main-thread?date=YYYY-MM-DD`
- **逻辑**:取当日及前 3 天文章 → `_rows_to_articles(rows)`(来自 `scripts/newsletter.py`,**已填 `so_what`**)→ `cluster_stories(day, report_date)`(`processor/reporter.py`)。
- **返回结构**:
  ```json
  {
    "report_date": "2026-07-12",
    "stories": [
      {
        "title": "代表文章标题",
        "entity": "GPT" | null,
        "summary": "围绕「GPT」的 5 篇相关报道。...",
        "heat": 65,
        "article_ids": ["https://...", "..."],
        "articles": [
          {
            "title": "...", "url": "https://...", "source_name": "...",
            "summary": "...", "tags": [...], "importance": "high|medium|low",
            "reason": "...", "published_at": "2026-07-12T...",
            "so_what": "对中小团队意味着 API 成本大幅下降..." | null
          }
        ]
      }
    ],
    "total_stories": 4,
    "method": "rule-based heuristic ..."
  }
  ```
- **降级**:DB 不可达返回 `{stories: []}`;前端需按 `stories.length === 0` 隐藏。
- **客户端封装**:`frontend/src/api/client.js` 已存在 `getMainThread: (date) => request('/main-thread?date=...')`。

### 1.2 复用组件
- `frontend/src/components/MainThreadPanel.jsx`:侧栏现用组件,**可直接照抄其数据获取与降级逻辑**(`useEffect` + `api.getMainThread(date)` + `.catch(() => setData({stories:[]}))`)。
- `frontend/src/pages/DigestPage.jsx`:公开页已用 `mainThread?.stories` 渲染主线,排版思路可参考(尤其 `s.entity` 标签、`s.title`、文章 `<a>` 列表)。

### 1.3 首页挂载点
- `frontend/src/pages/Home.jsx`:
  - `selectedDate`(来自 `useReport`)可直接作为 `date` prop 传入。
  - 主内容列结构(由外到内):`FilterBar` → `RecommendationWidget` → `<div className="flex-1 ...">` 滚动容器 → 内部依次:`DateNav` / `DataStats` / `HeroArticle` / 文章分组列表 / `SubscribeBox`。
  - **挂载位置**:把 `<DailyBriefing date={selectedDate} />` 放在滚动容器内的**第一个子元素**(即 `DateNav` 之前),使其成为首屏第一眼内容。

### 1.4 设计令牌(沿用,勿硬编码新颜色)
- 背景块:`var(--color-bg-off)`;边框:`var(--color-border-light)`;
- 标题:`var(--color-text-title)`;正文:`var(--color-text-body)`;次要:`var(--color-text-muted)`;最弱:`var(--color-text-label)`;
- 链接/强调:`var(--color-blue-link)`;
- 实体标签(参考 DigestPage 用法):浅底 `#eef2ff` + 字 `#4338ca`,圆角 pill;
- 字体:标题可用 `font-heading` / `'Source Serif 4', Georgia, serif`(与 DigestPage h1 一致)。

## 2. 设计方案

### 2.1 信息层级(每块主线卡片)
```
[实体 pill]  主线代表标题
围绕「实体」的 N 篇相关报道。 <— summary
💡 编辑部观点: <so_what 文本>   <— 仅在有 so_what 时显示,高亮块
  · 文章1标题 — 来源        (可展开:默认 2~3 条,「展开全部 N 篇」)
  · 文章2标题 — 来源
[分享今日速览]  [查看完整简报 ↗]   <— 链接到 /digest/{date}
```

### 2.2 视觉
- 整体包一个 `border-radius: 8px` 卡片,`background: var(--color-bg-off)`,`padding: 16~20px`,与 `SubscribeBox` / `DataStats` 视觉呼应。
- 区块标题:`🧭 今日速览` + 右侧小字 `事件聚类自动生成 · {date}`。
- `so_what` 用浅色高亮块(参考 newsletter 邮件 `#92400e` 文案色或站内 `--color-text-label` 做弱强调),前缀「💡 编辑部观点」以强化差异化人设。
- 卡片之间 `space-y-3`~`space-y-4`。
- 默认展示 Top **3** 条主线;`total_stories > 3` 时在底部加「查看完整简报 ↗」(`/digest/{date}`),不在首页罗列全部,保首屏轻量。

### 2.3 移动端
- 该组件在滚动列内,天然随列宽自适应,**无需 `lg:` 断点**;窄屏自动获得主线展示(修复当前移动端无主线的缺口)。
- 长标题/来源换行处理用 `flex-wrap`。

### 2.4 分享按钮(低成本,启动传播机制)
- 「分享今日速览」按钮:`navigator.clipboard.writeText(window.location.origin + '/digest/' + date)`,点击后按钮文案临时变「已复制链接 ✓」。
- 仅前端,无后端改动。若担心兼容性,可用 `document.execCommand('copy')` 兜底。

## 3. 实现步骤(原子化、有序)

### Step 1 — 新建组件 `frontend/src/components/DailyBriefing.jsx`
- 照抄 `MainThreadPanel` 的数据获取骨架(`useEffect` + `api.getMainThread(date)` + catch 降级)。
- 新增 state:`expanded`(bool,控制是否展开某条主线的全部文章)。
- 渲染逻辑:
  - `if (loading && !data) return null;`(加载中不占版面)
  - `const stories = data?.stories || []; if (!loading && stories.length === 0) return null;`
  - 取 `stories.slice(0, 3)` 渲染。
  - 每条主线:实体 pill + `s.title` + `s.summary`;若有代表文章 `so_what`(取 `s.articles[0]?.so_what`)则渲染观点块;文章列表默认 `slice(0,3)`,超出的用「展开全部 {n} 篇」按钮切换 `expanded`。
  - 文章 `<a href={a.url} target="_blank" rel="noreferrer">`,与 `MainThreadPanel` 一致。
  - 底部:「分享今日速览」按钮(复制 `/digest/{date}`)+「查看完整简报 ↗」链接(`/digest/{date}`)。

### Step 2 — 挂载到 `Home.jsx`
- 顶部 `import DailyBriefing from '../components/DailyBriefing';`
- 在滚动容器内、`{reports.length > 0 && (...DateNav...)}` **之前**插入:
  ```jsx
  <DailyBriefing date={selectedDate} />
  ```
- 不需要改动 `useReport`、不需要新接口。

### Step 3 — 侧栏 `MainThreadPanel` 去留(决策)
- **默认:保留侧栏 `MainThreadPanel` 不变。** 理由:DailyBriefing 在窄屏顶替它,宽屏下它是「速览详情」的补充(宽屏用户可在右侧看到完整主线列表)。两者数据同源、内容不冲突,且保留改动最小、风险最低。
- 若新会话执行后觉得重复,可后续把侧栏面板改为「仅当速览未展开时显示更多」——但**本计划不在 P0 做此改动**。

### Step 4 — 加载/空/错态
- 加载中:返回 `null`(不闪烁)。
- 空数据(`stories.length === 0`):返回 `null`(首页照常显示文章列表)。
- 接口异常:`MainThreadPanel` 已验证 `.catch(() => setData({stories:[]}))` 模式有效,照搬。

### Step 5 — 构建与冒烟
- `cd frontend && npm run build`(产物入 `frontend/dist`)。
- 本地预览或部署后,首页首屏应见「今日速览」;打开 DevTools Network 确认 `/api/main-thread?date=...` 200。
- 缩窄窗口验证移动端显示。
- 临时改 `getMainThread` 模拟 500/catch 验证静默降级(或断网测)。

## 4. 关键代码片段(骨架,供直接落地)

```jsx
// frontend/src/components/DailyBriefing.jsx
import { useState, useEffect } from 'react';
import { api } from '../api/client';

export default function DailyBriefing({ date }) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(false);
  const [expanded, setExpanded] = useState(false);

  useEffect(() => {
    if (!date) return undefined;
    let cancelled = false;
    setLoading(true);
    api.getMainThread(date)
      .then((d) => { if (!cancelled) setData(d); })
      .catch(() => { if (!cancelled) setData({ stories: [] }); })
      .finally(() => { if (!cancelled) setLoading(false); });
    return () => { cancelled = true; };
  }, [date]);

  const stories = (data && data.stories) || [];
  if (!loading && stories.length === 0) return null;

  const top = stories.slice(0, 3);
  const share = () => {
    const link = `${window.location.origin}/digest/${date}`;
    navigator.clipboard?.writeText(link).catch(() => {});
  };

  return (
    <section style={{ borderRadius: '8px', padding: '16px 20px', background: 'var(--color-bg-off)', border: '1px solid var(--color-border-light)', marginBottom: '20px' }}>
      <div style={{ display: 'flex', alignItems: 'baseline', justifyContent: 'space-between', marginBottom: '12px' }}>
        <h2 style={{ fontFamily: "'Source Serif 4', Georgia, serif", fontSize: '16px', fontWeight: 700, color: 'var(--color-text-title)', margin: 0 }}>
          🧭 今日速览
        </h2>
        <span style={{ fontSize: '11px', color: 'var(--color-text-label)' }}>事件聚类自动生成 · {date}</span>
      </div>

      <div className="space-y-4">
        {top.map((s, i) => {
          const lead = s.articles?.[0];
          const soWhat = lead?.so_what || null;
          const shown = expanded ? s.articles : (s.articles || []).slice(0, 3);
          return (
            <div key={s.title || i}>
              <div style={{ fontSize: '14px', fontWeight: 600, color: 'var(--color-text-title)', lineHeight: 1.4 }}>
                {s.entity && (
                  <span style={{ fontSize: '11px', padding: '1px 8px', borderRadius: '999px', background: '#eef2ff', color: '#4338ca', marginRight: '6px' }}>{s.entity}</span>
                )}
                {s.title}
              </div>
              {s.summary && <p style={{ fontSize: '12px', color: 'var(--color-text-muted)', margin: '2px 0 0', lineHeight: 1.5 }}>{s.summary}</p>}
              {soWhat && (
                <div style={{ fontSize: '12px', lineHeight: 1.6, color: '#92400e', marginTop: '6px', padding: '6px 10px', background: 'rgba(146,64,14,0.06)', borderRadius: '4px' }}>
                  💡 编辑部观点:{soWhat}
                </div>
              )}
              <ul style={{ listStyle: 'none', margin: '6px 0 0', paddingLeft: 0 }} className="space-y-1">
                {shown.map((a, j) => (
                  <li key={a.url || j}>
                    <a href={a.url} target="_blank" rel="noreferrer" style={{ fontSize: '12px', color: 'var(--color-blue-link)', textDecoration: 'none' }}>{a.title}</a>
                    {a.source_name && <span style={{ fontSize: '10px', color: 'var(--color-text-label)', marginLeft: '4px' }}>· {a.source_name}</span>}
                  </li>
                ))}
              </ul>
              {(s.articles?.length || 0) > 3 && (
                <button onClick={() => setExpanded(v => !v)} style={{ fontSize: '11px', color: 'var(--color-text-muted)', background: 'none', border: 'none', cursor: 'pointer', padding: '4px 0' }}>
                  {expanded ? '收起' : `展开全部 ${(s.articles || []).length} 篇`}
                </button>
              )}
            </div>
          );
        })}
      </div>

      <div style={{ display: 'flex', gap: '12px', marginTop: '14px', fontSize: '12px' }}>
        <button onClick={share} style={{ color: 'var(--color-text-muted)', background: 'none', border: 'none', cursor: 'pointer', padding: 0 }}>分享今日速览</button>
        <a href={`/digest/${date}`} target="_blank" rel="noreferrer" style={{ color: 'var(--color-blue-link)', textDecoration: 'none' }}>查看完整简报 ↗</a>
      </div>
    </section>
  );
}
```

> 注:`expanded` 当前是全局一个开关(展开即全部主线展开)。如想逐条独立展开,把 `expanded` 改为 `Set<number>` 即可——P0 先用全局开关够用。

## 8. 风险与注意

- `so_what` 依赖采集期 AI 生成;某日若 `so_what` 普遍为空,速览会少「观点」亮点——但主线与摘要仍在,不影响功能。无需为此加兜底。
- `getMainThread` 拉取前 3 天共 300 篇做聚类,数据量可控;若未来文章量暴涨导致首屏变慢,可加 `useMemo`/缓存(当前无需)。
- 不要在本计划内改 `cluster_stories` 或新增接口——保持纯前端组装,确保「天级工程、零后端风险」。
