## Step 8 — 播客 RSS（计划 §2.2）

```
你是 Signal（D:\MyPrograms\ai-industry-digest）的代码助手。请完成「播客 RSS」——把每日简报多做一个**音频形态**，对标 Rundown 的 audio。

先读（必读，确认现实约束）：
- docs/改造计划.md 的「## 3. 叙事 + 多形态 → ### 2.2」
- api/routes/public_digest.py（已完成 §2.3：复用其 PUBLIC_BASE_URL 常量、cluster_stories 同源数据口径、SEO 渲染层思路）
- processor/reporter.py 的 cluster_stories()（今日主线，音频脚本同源）
- frontend/src/components/ArticleReader.jsx（确认：现有"TTS"只是浏览器 Web Speech API，只能在用户浏览器朗读，**产不出 mp3 文件**）

⚠️ 关键现实修正：仓库里**没有服务端 TTS、没有 podcast RSS**。计划 §2.2 写的"复用现有 TTS 能力"并不成立——现有 TTS 是客户端浏览器能力，无法复用。因此本步需要**新增**一个服务端 TTS 步骤（不要假设已有，也别在代码里白找）。

具体做：
1. 新增服务端 TTS 封装（scripts/ 或 api/services/ 下）。默认用 edge-tts（免费、无需 API key，`pip install edge-tts` 装进 agent-reach 隔离 venv）；OpenAI TTS 作为可选（有 OPENAI_API_KEY 时启用）。封装一个 `text_to_mp3(text, out_path)` 函数，失败时抛异常由上层捕获。
2. 新增 scripts/podcast.py：
   - `build_script(date)`：复用 cluster_stories() 同份数据 + 文章 summary/so_what，拼一段**口语化播报稿**（今日主线逐条 + Top N 文章标题+一句话 so_what），带轻量开场/收尾，不照抄邮件 HTML。纯函数、不依赖 TTS，便于单测。
   - `generate(date)`：调 build_script → 调 text_to_mp3 生成 `media/podcast/{date}.mp3`（目录不存在则建）；记录字节长度供 RSS 的 length 字段。
   - 优雅降级：TTS 失败 / 当天无文章 → **跳过该天、不抛错**，不写进 RSS（避免坏 enclosure）。
3. 静态托管音频：在 api/main.py 用 StaticFiles 把 `/podcast` 挂到 `media/podcast/`（与现有 frontend/dist 挂载并存，注意挂载顺序/路径不冲突）。enclosure URL 用 `{PUBLIC_BASE_URL}/podcast/{date}.mp3` 绝对地址（复用 public_digest 的 PUBLIC_BASE_URL 取值逻辑，允许环境变量覆盖）。
4. 新增 `GET /podcast.xml`（api/routes/ 下，或并入 public_digest 路由文件）：列出最近 N 天（如 30）**已生成音频**的日期，输出标准 podcast RSS（rss→channel→item：title / description / pubDate / guid / enclosure url=绝对 mp3, type="audio/mpeg", length=字节数）。仅含确有音频的日期（无音频不列，避免坏链）。
5. 接 .github/workflows/daily.yml：在邮件简报 job 之后加一步 `python scripts/podcast.py generate --date <当天>`（或直接 `generate` 取当天），失败不阻断主流程（continue-on-error，音频是加成项）。
6. 新增 tests/test_podcast.py（纯逻辑、不连 Supabase、不真调 TTS）：
   - build_script 用 mock 数据产出非空播报稿、含主线与 so_what 字样；
   - 给定日期列表，RSS XML well-formed、每项 enclosure 为绝对 URL、length 为整数、仅列确有音频的日期；
   - text_to_mp3 在 edge-tts 未安装时测试 skip（pytest.importorskip），不强制环境。

验收：本地 `python scripts/podcast.py generate --date 2026-07-10` 产出 mp3；`GET /podcast.xml` 返回合法 RSS、enclosure 为 https 绝对地址、当日可播；pytest 全绿、现有 129+ 测试无回归；daily.yml 新 step 语法正确（act/dry-run 验证）。
约束：不引入重依赖（edge-tts 轻量即可，OpenAI TTS 仅可选）；不碰邮件/退订/像素逻辑；不做真人配音/剪辑；与 §2.3 同源复用 cluster_stories 与 PUBLIC_BASE_URL。
完成后：在改造计划.md §2.2 标注已完成(YYYY-MM-DD) + 变更文件清单；并提醒用户开新对话贴 Step 9 提示词。
```
